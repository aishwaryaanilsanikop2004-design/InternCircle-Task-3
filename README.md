# InternCircle Task 3 - Number Guessing Game & Word Counter

## Features
- Random number guessing game
- Attempt counter
- Scoring system
- Text file reading
- Word frequency analysis
- Input validation using loops

## How to Run
1. Install Python 3.
2. Keep `main.py` and `words.txt` in the same folder.
3. Open a terminal in that folder.
4. Run:
   `python main.py`

## Test
Choose option 1 to play the guessing game.
Choose option 2 to analyze `words.txt`.
